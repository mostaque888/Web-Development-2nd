This project responds to the BigPlanetarium client brief by creating an accessible educational website prototype about the Milky Way and the planets. The client asked for a landing page, at least one page dedicated to a specific planet, captivating images, and videos and/or other interactive media. The brief also states that the additional requirement is accessibility, so the website was designed to be perceivable, operable and understandable for a range of users (BigPlanetarium client brief, 2026).
